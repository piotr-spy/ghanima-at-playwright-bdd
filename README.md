## Playwright + Cucumber + Allure Template
This project is a starter framework for functional and E2E testing in BDD paradigm, using [Playwright](https://playwright.dev/), [Cucumber](https://cucumber.io/docs/), and [Allure](https://allurereport.org/docs/) reporting. It is designed to support scalable, maintainable, and readable automated tests using the Page Object Model (POM) pattern.

## Features
- **Playwright** for fast, reliable browser automation.
- **Cucumber** for writing tests in Gherkin syntax (Given/When/Then). Bridges the gap between technical and business stakeholders, making test coverage, requirements, and reporting more meaningful and accessible to all team members.
- **Allure** integration for rich visual test reports.

## Requirements
- https://nodejs.org/en - Node 22.14.0 or higher LTS
- https://www.oracle.com/java/technologies/downloads/ - JDK 21 or higher LTS required for Allure

## Installation
- Clone the repository
- Make sure you have full read/write rights to the local repository folder
- **npm install**

## Running tests
- Open the **runtests.sh** file to set the test run options
- Copy the file path and run it in terminal
- Open **index.html** reports in **allure-report** subfolders to analyse results
